Din karaktär

Quest-texter som läses upp

Addonen läser upp quest-texter, NPC-dialog och böcker. Den har två röster:

  1. Direkt röst: spelets inbyggda talsyntes. Den fungerar direkt utan installation, men låter som datorns standardröst.
  2. AI-röst med öppen källkod: klipp som du skapar på din egen dator med en modell i nivå med ElevenLabs. Varje NPC får en egen, fast röst.

Addonen spelar AI-klippet om det finns. Annars använder den spelets röst och lägger texten i kö till nästa gång.

1. SpelaAddonen läser upp med spelets röst och sparar nya texter när du loggar ut.
2. Skapa rösterKör forever_voice.py. Den gör .ogg-klipp av texterna i kön.
3. Starta om speletKlippen spelas nu automatiskt nästa gång du möter samma text.

Addons får inte prata med andra program medan spelet körs. Därför skapas rösterna mellan spelsessionerna. Verktyget läser bara addonens sparfil och skriver ljudfiler. Det rör aldrig själva spelet.

Installera

Addonen

  1. Hämta mappen forever/addon från GitHub.
  2. Kopiera ForeverGuide och ForeverGuide_Voices till spelets Interface/AddOns. I betan heter spelmappen _classic_beta_ eller liknande.
  3. Starta spelet och skriv /fg för att se alla kommandon.

Röstverktyget

cd forever/companion
pip install numpy soundfile kokoro
python forever_voice.py --wow "C:/Program Files (x86)/World of Warcraft/_forever_" --dry-run
python forever_voice.py --wow "C:/Program Files (x86)/World of Warcraft/_forever_"

Battle.net API (frivilligt)

Med blizzard_fetch.py hämtar du klasser, raser och din karaktärs statistik. Skriptet skriver ut samma exporttext som addonen.

set BLIZZARD_CLIENT_ID=...
set BLIZZARD_CLIENT_SECRET=...
python blizzard_fetch.py character --realm din-realm --name Oskar

Lägg aldrig din client secret på den här webbsidan. Allt på GitHub Pages är offentligt. Blizzard har ännu inte sagt vilken namespace WoW: Forever får i API:et, så verktyget använder Classic Era tills vidare.

Fler funktioner att bygga

Upplevelse och berättelse

  • Svensk översättning: översätt quest-texterna lokalt och läs upp dem med en svensk röst.
  • Röster per folk: referensklipp för dvärgar, orcher och alver, så att röst och accent passar NPC:n.
  • Äventyrsdagbok: spara alla quests du läst och visa dem som en berättelse här på webben.
  • Zonpaket: skapa alla röster för en zon i förväg och dela paketet med vänner.

Hjälp att komma vidare

  • Uppgraderingsråd: visa i tooltipen hur mycket ett föremål höjer din skada, baserat på simulatorns statvikter.
  • Hardcore-varning: röstvarning vid låg hälsa, elitfiender och fiender långt över din nivå.
  • Levlingsrutt: föreslår nästa quest och zon utifrån nivå, klass och fraktion.
  • Talang- och yrkesplanerare: kopplad till klassvalet i början.

Tillgänglighet

  • Större text och dyslexivänligt typsnitt i quest-fönstret.
  • Justerbar talhastighet per NPC-typ.
